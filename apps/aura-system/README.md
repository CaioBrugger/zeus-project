# @zeus/aura-system

Internal design-system package for Zeus Project.

- atomic CSS layers
- HTML component snippets
- AI SaaS template page
- React/Next starter kit
- Tailwind token mapping

- `styles/template.css`
- `tokens.json`
- `tailwind.tokens.js`
- `react/app.page.tsx`
- `templates/page-starter.html`
- `react/templates/PageStarter.tsx`
