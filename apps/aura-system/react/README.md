# Aura System React

React/Next-ready implementation of the extracted Aura design system.

## Suggested structure

- `app/page.tsx`: landing template
- `components/`: reusable atoms, molecules, and organisms
- `styles/aura.css`: imported tokenized stylesheet

## Usage

1. Copy the `react/components` folder into your Next app.
2. Copy `react/styles/aura.css` or import from the local `../styles/` files.
3. Use `app/page.tsx` as a starting point for AI SaaS landing pages.
